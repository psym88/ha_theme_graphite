# Changelog

All notable changes to this theme are documented here. The versions are the tags of the
[GitHub releases](../../releases), which is what the Marketplace and HACS hand out.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) with the theme variables
as the public surface: a new variable is a minor, a colour that moves is a patch, a variable
that goes away or a theme name that changes is a major.
