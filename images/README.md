# Screenshots

Home Assistant shows the README of a theme repository, and the catalog only accepts a theme
whose README contains images. Two files belong here:

| File                     | Content                                              |
| ------------------------ | ---------------------------------------------------- |
| `graphite-light.png`     | A dashboard in light mode                            |
| `graphite-dark.png`      | The same dashboard in dark mode                      |

How to take them:

1. Install `themes/graphite.yaml` into your `config/themes/` and select **Graphite** in your
   profile.
2. Use a dashboard that shows a mix of things: tiles with icons, a couple of gauges or
   history charts, an entity with a switch, a media player, a weather card.
3. Set the mode to light, take the screenshot, set it to dark, take the same one.
4. Export at around 1000-1400 px wide, PNG or WebP. Same crop for both, so the pair reads as
   one comparison.

The two paths are referenced in `README.md`. Keep the names, or change both places.
